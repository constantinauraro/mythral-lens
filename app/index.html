Mythral Lens

by MythralCreations

Load a Minecraft build and spin it in 3D. Everything runs in your browser; your files never leave your computer.

Original game textures

Load a texture pack once. The app saves it and uses it automatically from then on.

No Minecraft installed: the official Mojang pack

Open github.com/Mojang/bedrock-samples, click the green “Code” button, then “Download ZIP”. Load the downloaded archive here without unzipping it. It is a large archive, so reading it can take a minute.

Have Minecraft Java? Use the .jar file

Windows: press Win+R, type %appdata%\.minecraft\versions and open the version folder (e.g. 1.21.1). It contains 1.21.1.jar.

macOS: ~/Library/Application Support/minecraft/versions. Linux: ~/.minecraft/versions.

If the version is missing, launch it once from the launcher so it downloads.

Until then you see approximate built-in textures.
